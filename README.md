# Fluid-Simulation

This is an implementation of a dynamic fluid mechanics algorithm present in modern video games. This project was inspired from Jos Stam's paper on [Dynamic Fluid Mechanic](http://graphics.cs.cmu.edu/nsp/course/15-464/Fall09/papers/StamFluidforGames.pdf).

# Implementation Details

- C++20   ![C++](https://img.shields.io/badge/-C++-blue?logo=cplusplus)
- OpenGL  ![OpenGL](https://img.shields.io/badge/OpenGL-5586A4?style=flat-square&logo=opengl&logoColor=white)
- GLFW ![GLFW](https://img.shields.io/badge/GLFW-Windowing%20Library-FFFFFF?style=for-the-badge&logo=glfw&logoColor=white)
